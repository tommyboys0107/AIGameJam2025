# Product Overview

**AIGJ2025** is a Unity game project developed for what appears to be a game jam or competition (based on the naming convention).

- 2D game with comprehensive player controls including movement, combat, and interaction systems
- Multi-platform input support (keyboard/mouse, gamepad)
- Universal Render Pipeline (URP) for optimized 2D rendering

## Target Platforms
The project is configured to support multiple input methods suggesting cross-platform deployment:
- PC (Keyboard & Mouse)
- Console (Gamepad)
